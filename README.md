# 本地语音输入

按一下键，说一句话，文字直接出现在光标处。全部在本机跑，不联网，不上传，没有额度限制。

Windows 专用。用 [faster-whisper](https://github.com/SYSTRAN/faster-whisper) 做识别。

---

## 它做什么

- **按键说话**：右 Ctrl 按住说，松开出字；或者轻点一下开始、再点一下结束
- **鼠标侧键**：按一下开始，再按一下结束（会拦截侧键，不再触发"后退/前进"）
- **自动静音背景音乐**：录音时把默认播放设备静音，说完自动恢复，免得音乐混进麦克风
- **自动清理**：去掉"嗯、呃、那个、就是说"，补全标点
- **热词纠错**：把常用的错听词自动换成正确写法，改文件即时生效
- **浮窗**：录音时显示电平条，转写时显示"识别中…"，完成显示字数
- **两种投递方式**：默认用 SendInput 逐字注入，不碰剪贴板；也可以切成"写剪贴板 + 合成 Ctrl+V"，对某些自绘控件更稳，还能配合跨屏软件把字送到另一台机器
- **单实例**：重复启动会自己退出，不会两个程序抢热键
- **日志轮转**：日志超过 5MB 自动转存一份 `.1`，不会无限变长

## ⚠️ 它动了你系统的哪些东西

这个程序需要比较高的权限才能工作，先说清楚：

| 行为 | 为什么 | 能关吗 |
|---|---|---|
| 装**全局键盘钩子** | 才能在任何程序里按热键 | 不能，这是核心功能 |
| 装**底层鼠标钩子** | 拦截侧键，否则按侧键会触发网页后退 | `suppress_side_buttons`: `false` |
| **模拟按键**输入文字 | 把识别结果打进光标处 | 不能，这是核心功能 |
| 录音时**静音默认播放设备** | 防止音乐被一起录进去 | `mute_background`: `false` |

**不联网。** 模型下载完成后，整个程序不产生任何网络请求，录音和文字都不出本机。

因为要装键盘鼠标钩子，**部分杀毒软件会报毒**。源码全在这，可以自己看。介意就别用。

## 系统要求

- Windows 10 / 11
- Python **3.10 或 3.11**（3.12+ 上 `keyboard` 库可能装不上）
- 麦克风（笔记本自带麦克风就行）
- **显卡可选**：有 NVIDIA 显卡会快很多；没有也能跑，会自动退回 CPU 和小模型

速度参考（RTX 4080 + large-v3 实测）：15 秒的话，约 1.3 秒出字。
CPU 上会明显慢，具体取决于你的 CPU。

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## 第一次运行

双击 `start_voice.vbs`（无窗口启动）。

首次启动会**下载模型**，视网络情况要几分钟到几十分钟：

| 配置 | 模型 | 大小 |
|---|---|---|
| 有显卡 | large-v3 | 约 3 GB |
| 没有显卡 | small | 约 500 MB |

下载源默认用 `hf-mirror.com`（国内可访问）。如果你在境外，或者想用官方源，先设环境变量：

```bat
set HF_ENDPOINT=https://huggingface.co
```

模型只下一次，之后从本地缓存加载，通常十几秒就绪。

## 怎么用

1. 光标点到你想输入的地方（记事本、微信、浏览器，都行）
2. **按住右 Ctrl** 说话，松开就出字
3. 或者**轻点右 Ctrl** 开始，说完再点一下结束（适合说长句）
4. 或者按**鼠标侧键**，同样是一下开始、一下结束

右 Ctrl 轻点和按住会自动区分：按得短（不到 0.5 秒）是开关式，按住不放是对讲式。

## 配置

首次运行会在同目录生成 `config.json`：

```json
{
  "hotkey": "right ctrl",
  "model": "auto",
  "language": "zh",
  "device_hint": "",
  "mute_background": true,
  "clean_fillers": true,
  "suppress_side_buttons": true
}
```

| 键 | 说明 |
|---|---|
| `hotkey` | 键盘热键，如 `right ctrl`、`f8`、`caps lock` |
| `model` | `auto` / `tiny` / `base` / `small` / `medium` / `large-v3` |
| `language` | 语言代码，`zh` / `en` / `ja`…；填 `""` 自动判断 |
| `device_hint` | 麦克风名字里的关键词；留空 = 系统默认输入设备 |
| `mute_background` | 录音时是否静音其它声音 |
| `clean_fillers` | 是否去掉"嗯、那个" |
| `suppress_side_buttons` | 是否拦截鼠标侧键 |
| `output` | 投递方式：`inject`（逐字注入，默认）/ `clipboard`（写剪贴板 + 合成粘贴） |
| `clipboard_paste_method` | 剪贴板模式下怎么粘：`sendinput` / `message`（WM_PASTE）/ `auto` |
| `clipboard_sync_delay` | 写剪贴板后等多久再发粘贴键（跨屏软件同步用），默认 0.30 秒 |
| `clipboard_verify_timeout` | 粘贴后等目标控件文本变化的时间，默认 0.80 秒 |
| `clipboard_rewrite_tries` | 粘贴前发现剪贴板被改写时最多重写几次 |
| `paste_mod_wait` | 粘贴前等物理修饰键松开的上限，默认 1.5 秒 |
| `remote_port` / `remote_token` / `remote_bind` | 跨机模式用，见下面"跨机使用"；默认关闭 |

改完重启程序生效。`hotwords.txt` 和 `whisper.txt` 是即时生效的。

### 投递方式怎么选

| | `inject`（默认） | `clipboard` |
|---|---|---|
| 原理 | 逐字 SendInput 注入 | 写剪贴板后合成 Ctrl+V |
| 剪贴板 | 不动 | **会覆盖你剪贴板里的内容** |
| 适用 | 绝大多数输入框 | 自绘控件、浏览器渲染框，或配合跨屏软件 |
| 失败时 | 无痕迹 | 文字留在剪贴板，手动 Ctrl+V 即可 |

### 跨机使用（可选）

如果你用 Mouse Without Borders 之类的软件在两台机器间共享键鼠，可以把 `output` 设成 `clipboard`：
识别结果会写进剪贴板，再合成 Ctrl+V，按键由跨屏软件转发到光标所在的那台机器，文字就落在那边。

如果还想在**另一台机器的键盘**上按热键触发，把 `remote_agent.py` 拷到那台机器、配上
`remote_host` / `remote_port` / `remote_token`，并在这台机器的 `config.json` 里打开
`remote_port` 和同一个 `remote_token`。监听地址可用 `remote_bind` 收窄到具体网卡。

### 不知道麦克风叫什么

```bat
.venv\Scripts\python voice_input.py --devices
```

会列出所有输入设备，把名字里的关键词填进 `device_hint` 就行。

### 换热键的坑

**别用 `right alt`。** Windows 把它当 AltGr，会产生一对合成的按下/松开事件，程序会误判成"瞬间松手"，一按就结束。

右 Ctrl 是实测好用的。左 Ctrl 会和常用快捷键冲突，不建议。

## 已知限制

- **不做流式**。说完整句才出字，不是边说边出。切段会打断词、错字率上升，所以没做
- **Windows 专用**。键盘鼠标钩子、SendInput 都是 Win32 的东西
- **Whisper 会对静音瞎编**。程序已经用"有声帧比例"过滤过，但如果环境噪声很大，仍可能蹦出莫名其妙的一句
- **中文标点是补出来的**。Whisper 本身不太输出句末句号，靠规则补，偶尔会有多余或缺失
- **剪贴板模式会覆盖剪贴板**。换来的是更强的兼容性；失败时文字还在剪贴板里，手动 Ctrl+V 能救回来
- **按住热键说时，热键本身仍是 Ctrl**。误触其它键会变成 Ctrl 组合键（比如 Ctrl+S），说话时尽量别碰键盘

## 出问题了

日志在 `voice_input.log`，每次录音都有一行，带失败码：

| 失败码 | 意思 |
|---|---|
| `OK` | 正常 |
| `TOO_SHORT` | 太短，不到 0.4 秒 |
| `DEVICE_NO_DATA` | 打开了设备但一帧数据都没收到 |
| `DEVICE_SILENT` | 设备送的是数字静音（-90 dB 那种） |
| `NO_SPEECH_DETECTED` | 有声帧比例太低，判定为没人说话 |
| `ASR_EMPTY_RESULT` | 模型跑了但没出字 |
| `ASR_ERROR` | 模型报错 |

常见原因：

- **按了没反应** → 先看进程在不在，再看日志最后一行
- **对着某个程序说话没反应，别的程序正常** → 那个程序是以管理员身份运行的。Windows 不允许普通权限的钩子往高权限窗口输入，把语音输入也用管理员身份启动就行
- **一直是 DEVICE_SILENT** → 换一个 USB 口。有些口供电不足，设备枚举正常但不送数据
- **系统采样率和设备对不上** → 程序会自己试 16k / 44.1k / 48k，日志里会写实际用的哪个
- **识别很慢** → 多半是退回 CPU 了，看日志里"模型就绪"那行
